# Wikipedia-Golf

ウィキペディアのゴルフができるサイト

[ここから遊べるよ](https://wikipedia-golf.vercel.app/)

## 今日のお題について

「今日のお題」は毎日午前0時（JST）に自動更新されます。

- GitHub Actions が `public/daily-challenge.json` を補充します。ファイルには常に今日から 14 日分のお題が入っているため、Actions が失敗しても途切れません
- お題は「良質な記事」「秀逸な記事」から選び、ゴールは被リンク 50 件以上、スタートは発リンク 30 本以上で、スタートからゴールへ直接リンクしていないものだけを採用します
- クライアントはファイルから今日の分を読むだけで、ブラウザ側で記事を探索することはありません

詳細は [scripts/README.md](scripts/README.md) をご覧ください。
